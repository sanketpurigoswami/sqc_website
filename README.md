
# SQC – Super Quant Coders Club Website

I am a **Sanket Puri, a B.Tech CSE student at NIT Jalandhar**, and I created this website to introduce people to the **SQC (Super Quant Coders) Club**.

This website is built **purely using HTML, CSS, and JavaScript**, without any backend, frameworks, or external dependencies. It is a **single-page static website** whose main purpose is to present information about the club, its team, activities, and upcoming events in a clean and modern way.

---

## About the Project

* Single-page static website
* No backend involved
* No frameworks or libraries used
* Focused on design, animations, and smooth user experience
* Intended as an introductory website for the SQC club

The site includes:

* A landing/hero section
* Information about what the club does
* Team members section
* Upcoming events section
* A contact form (frontend-only)

---

## Tech Stack Used

* **HTML5** – Page structure
* **CSS3** – Styling, layout, animations, responsiveness
* **JavaScript (Vanilla)** – Interactions, animations, smooth scrolling

No React, no Bootstrap, no Tailwind, no backend services.

## How to Run the Website

Since this is a static site, there is no setup required.

1. Clone or download the repository
2. Open `index.html` in any modern web browser

That’s it.

---

## Notes

* The contact form does not send real messages (frontend-only)
* Images should be placed in the same folder as `index.html`
* The website is responsive and works on both desktop and mobile devices
